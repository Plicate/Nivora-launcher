# Test Sidebar Tab

This fixture adds a `Test Tab` item to the launcher sidebar when installed and enabled.

1. Open **Plugins** and choose **Add archive**.
2. Select `test-sidebar-tab.zip` and confirm the archive.
3. In the local plugin list, turn on **Test Sidebar Tab**.
4. Select **Test Tab** under **Plugin Tabs** in the sidebar.

The page is a host-rendered placeholder. The `main.js` entrypoint is required by the current archive format, but it is intentionally inert and is never executed.

# Тестовая sidebar-вкладка

Этот fixture добавляет пункт `Test Tab` в сайдбар лаунчера при установке и включении.

1. Откройте **Плагины** и выберите **Добавить архив**.
2. Выберите `test-sidebar-tab.zip` и подтвердите архив.
3. В списке локальных плагинов включите **Test Sidebar Tab**.
4. Выберите **Test Tab** в разделе **Вкладки плагинов** сайдбара.

Страница — placeholder, отрисованный хостом. Файл `main.js` требуется текущим форматом архива, но он намеренно инертен и никогда не исполняется.
